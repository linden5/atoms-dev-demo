# S8：真实 LLM 生成 + 发布闭环 + 版本叙事

> 计划见 [../sprint-s8.md](../sprint-s8.md)；本文记录**实际改了什么、怎么部署、怎么回滚、怎么验收**。
> 状态：✅ 完成——本地验收 + 公网部署均已落地（公网部署 2026-11-19，`ENGINE_MODE=llm`）。

## 1. 这一版要解决的问题

`/health` 长期显示 `engine=mock`：演示能跑，但"智能体生成"其实是固定模板，属于 PoC 观感。S8 把它换成真实生成，并补上"发布成别人能打开的链接"这一闭环。

## 2. 改动清单

### 2.1 真实生成引擎（新增 3 个文件）

| 文件 | 作用 |
|---|---|
| `app/engine/llm_engine.py` | 三次调用的引擎实现：`planning → coding → checking`，实现 `Engine.run` 契约，零新增依赖（`urllib.request` + `asyncio.to_thread`） |
| `app/engine/prompts.py` | 四段提示词（规划 / 编码 / 审查 / 修正）+ `render()`（用 `__KEY__` 占位符而不是 `str.format`，因为提示词里有 JSON 花括号） |
| `app/engine/html_utils.py` | `extract_html` / `inspect_html` / `external_refs` / `placeholder_hits`；从 `metagpt_engine` 抽出，两引擎共用同一套抽取规则（旧导入路径仍可用） |

`llm_engine` 的关键行为：

1. **编码不合格带原因重试一次**：`extract_html` → `inspect_html`（含 `<script|style>`、长度、`</html>` 闭合），第二次把失败原因拼进提示词；
2. **自检用结构化 JSON**：审查返回 `{"ok":bool,"issues":[]}`，解析失败按"无问题"处理（审查失败不该让任务失败）；本地体检发现外链资源或占位符会**追加**成问题；
3. **修正只做一次**：修正稿不合格就保留原稿（"宁可原稿能跑"）；
4. **错误映射成人话**：401→检查 Key、404→检查 `LLM_BASE_URL` 是否带 `/v1`、429→限流、超时→调 `LLM_TIMEOUT`；
5. **重试策略**：429/5xx/网络抖动重试一次，401/400 不重试；
6. **产物**：`index.html` + `meta.json`（`brief/title/issues/tokens/steps/elapsed_s`）。

### 2.2 引擎选择（改 2 个文件）

- `app/config.py`：新增 `ENGINE_MODE=llm|mock|metagpt|auto` 与 `LLM_BASE_URL / LLM_API_KEY / LLM_MODEL / LLM_TIMEOUT / LLM_MAX_TOKENS / LLM_TEMPERATURE`；旧的 `MOCK_ENGINE` 三态继续可用（`ENGINE_MODE` 优先）。
- `app/tasks.py::get_engine`：显式指定不降级；`auto` 顺序为 LLM（三项配齐）→ MetaGPT（可导入）→ MOCK。
- `/health` 增加 `model` 字段（只回显模型名，不回显 Key 与端点）。

### 2.3 发布 / 分享（改 4 个文件）

| 文件 | 改动 |
|---|---|
| `app/models.py` | 新增 `publishes` 表、`Publish` 数据类、`SLUG_PATTERN` / `normalize_slug` / `valid_slug` / `suggest_slug`；`Task` 增加 `version_title` |
| `app/db.py` | publish CRUD、`session_of_task`、`set_version_title`；`_migrate` 增加 `version_title` 列；**修正** `last_generated_task` 连 `tasks` 过滤 `status='succeeded'`（失败版本不再被当父版本） |
| `app/api.py` | `POST/GET /api/tasks/{id}/publish`、`GET /api/publishes`、`DELETE /api/publishes/{slug}`、`GET /p/{slug}`（+HEAD）、`/p/{slug}/files/{path}`、`GET /api/tasks/{id}/zip` |
| `app/security.py` | `/p/` 加入 `CSP_EXEMPT_PREFIXES`（公开页要有自己的宽松 CSP，且不能被 `X-Frame-Options: DENY` 拦住嵌入） |

发布语义：同版本重复发布幂等（200 `updated:false`）、同会话新版本发布同一地址是 Update（200 `updated:true`）、别的应用占用返回 409、非法格式 400、任务未成功 409。

### 2.4 前端（改 3 个文件）

- 顶栏新增 `Publish` / `Share`；发布面板含地址输入（`/p/` 前缀）、`Publish → Up to date → Update` 状态、`View app`、复制链接、`Unpublish`；分享面板含公开说明、复制链接、导出 ZIP。
- 预览区新增常驻提示条：`预览是工作副本，访客看到的是已发布版本`；已发布且最新时变绿显示线上地址，有未发布改动时提示"线上仍是旧版本"。
- 历史面板改成三标签：`版本`（Restore 切回预览）/`消息`（搜索 + 跳转定位，不改状态）/`会话`（原列表）。
- 版本卡片标题改用后端 `version_title`（LLM 引擎取简报里的「目标：」）；`重试` 改为"填回输入框"，不再自动重发（避免重复用户消息）；运行中显示已用时秒数；失败卡片给出分层建议。
- 顶栏版本号 `s6` 的硬编码改为 `s8`，`app/__init__.py` 的 `STEP` 同步为 `s8`。

## 3. 部署

本地/服务器都只需要三件环境变量：

```bash
ENGINE_MODE=llm
LLM_BASE_URL=https://api.deepseek.com/v1      # 任意 OpenAI 兼容端点，注意是否要带 /v1
LLM_MODEL=deepseek-chat
LLM_API_KEY=sk-...                             # 绝不进仓库
```

systemd（`deploy/atoms.service`）：

```ini
Environment=ENGINE_MODE=llm
Environment=LLM_BASE_URL=...
Environment=LLM_MODEL=...
EnvironmentFile=/etc/atoms/llm.env     # 里面只放 LLM_API_KEY=sk-...
```

步骤：

```bash
git pull
bash scripts/deploy.sh                 # 装依赖 + 重建 venv + 重启
curl -s http://127.0.0.1:8000/health    # 期望 step=s8 engine=llm model=非空
bash scripts/verify_s8.sh               # 期望 38 通过 / 0 失败
DEEP=1 bash scripts/verify_s8.sh        # 额外验 409 抢占（会多生成一次）
```

> 公网仍保持 `0.0.0.0:8000` + systemd 单 worker，不使用域名与 80/443。

## 4. 回滚

| 层级 | 操作 | 影响 |
|---|---|---|
| 只关真实生成 | `ENGINE_MODE=mock` 重启 | 演示回到固定模板，发布/版本功能仍可用，数据不动 |
| 只关发布入口 | 前端隐藏 Publish/Share 按钮；后端保留 `/p/` 路由 | 已发出的公开链接仍可访问（如需彻底下线，删 `publishes` 行） |
| 整体回退 | `git checkout s7 && systemctl restart atoms` | `publishes` 表与 `version_title` 列会被旧代码忽略（schema 只增不改，旧版本能正常启动） |

## 6. 已知限制

1. **未用真实 Key 跑过**：本地验证走 `scripts/fake_llm.py`；真模型的质量与耗时需要在部署时用 `gen_once.py` 再确认一次（3 条不同需求）。
2. **取消不会中断已发出的 LLM 请求**：HTTP 在线程里跑，无法 kill；任务状态立即变 `cancelled`，但那一次请求仍会计费。
3. **单文件产物**：只产出 `index.html`，多文件/资源目录还没有（`scan_artifacts` 支持，但提示词约束成单文件）。
4. **公开页无鉴权**：链接即是权限（与 Atoms 的 Public 一致），没有 Private 密码/口令。
5. **slug 不可换绑其他应用**：被占用只能改名，避免误把别人的链接指向新内容。
