## 两套 CSP 的分工

| 页面 | 策略 | 为什么 |
|---|---|---|
| 主站 `/`、`/styles.css`、`/app.js` | `default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; connect-src 'self'; frame-src 'self'; base-uri 'none'; form-action 'self'; object-src 'none'` | 主站代码全部可控，禁止内联脚本与外联资源；`frame-src 'self'` 允许嵌入同源预览 |
| 预览 `/api/tasks/**` | 沿用 S3 的 `api.PREVIEW_CSP`（允许 `'unsafe-inline'`、`data:`、`blob:`） | 生成代码是单文件内联页面，必须放宽；靠 iframe `sandbox="allow-scripts"`（**无** `allow-same-origin`）把它关进独立源 |
| `/api/docs` | 不套主站 CSP | Swagger UI 依赖 CDN，套上会白屏 |

配套响应头：所有响应 `X-Content-Type-Options: nosniff` + `Referrer-Policy: no-referrer`；主站 HTML 额外 `X-Frame-Options: DENY` + `Cache-Control: no-store`（部署后刷新即拿新版本）。预览页**不**带 `X-Frame-Options`，否则 iframe 加载会被拦。

## 状态覆盖

| 状态 | 表现 |
|---|---|
| 空态（还没有任务） | 预览区居中提示「还没有任务 / 在需求框里描述你想生成的应用」 |
| 空态（有任务但未选中） | 提示「选择一条任务」 |
| 生成中 | 阶段卡片点亮、预览区提示「正在生成…」，进入终态自动加载 |
| 预览加载中 | 画布上覆盖半透明加载层 + 旋转指示器；iframe `load` 后收起 |
| 加载超时 | 15s 未完成收起加载层并给出「可点刷新重试」 |
| 失败 | 红色横幅显示 `error` + 「重试」（同 prompt 新建任务） |
| 取消 | 阶段卡片标红，预览区提示「任务已取消」 |
| 产物缺失 | `/preview` 404，前端保持空态并提示，不白屏 |

## 怎么部署

无新依赖、无 schema 变更，覆盖代码重启即可：

```bash
cd ~/atoms-dev-demo
git pull
bash scripts/deploy.sh
curl -s localhost:8000/health   # 期望 "version":"1.0.0","step":"s6"
```

上线后确认头：

```bash
curl -sI http://127.0.0.1:8000/ | grep -i -E 'content-security-policy|x-frame-options|cache-control'
```

## 怎么验收

```bash
bash scripts/verify_s6.sh                 # S6 自身的 23 项
FULL=1 bash scripts/verify_s6.sh          # 再串跑 verify_s1…s5（全量回归）
TARGET=public FULL=1 bash scripts/verify_s6.sh   # 公网（外网跑，别在服务器上测公网 IP）
```

S6 检查项：步骤号、主站 CSP 与四条安全头、预览页独立 CSP 且无 `X-Frame-Options`、iframe `sandbox` 且无 `allow-same-origin`、空态/错误态/加载态元素齐全、四类 404（未知任务/预览/接口/路径穿越）、404 响应体不泄露服务端路径、`/api/docs` 豁免生效。

全量回归（本机实测，2026-11-19）：

```

verify_s3.sh  28 通过
```

浏览器确认（playwright-cli + 本地 Chromium）：严格 CSP 下样式与脚本正常、轮询可用、iframe 内容渲染、加载层正常收起、控制台 0 error；截图在 `logs/shots/s6-*.png`（不入库）。

## 怎么回滚

```bash
git checkout s5 && bash scripts/deploy.sh      # 回到 S5（仍带预览 CSP，只是没有主站安全头）
git checkout s3 && bash scripts/deploy.sh      # 回到最小可演示版本
```

数据库与产物目录无需回退。

## 已知限制

| 项 | 说明 |
|---|---|
| 无 HTTPS | 公网 IP + 8000 端口，明文传输（备案限制，见 design 5） |
| 无鉴权 | 单人演示场景，任何人拿到地址都能提交任务 |
| CSP 无 nonce | 主站用 `'self'` 而非 nonce，换来静态文件无需模板化；代价是无法内联脚本 |
| 生成代码的隔离强度 | `sandbox` 无 `allow-same-origin` 已阻断读 Cookie，但同源 + `allow-scripts` 仍允许它向 `/api/*` 发请求（不含凭证），属 design 已记录的取舍 |
| 未做限流 | 公网暴露时理论上可被刷任务；单 worker + 并发 1 自然限速，未额外加 token bucket |
